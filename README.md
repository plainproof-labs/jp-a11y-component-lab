# JP A11y Component Lab

Live site: https://jp-a11y-component-lab.pages.dev/

A tested Japanese disclosure-and-error component for designers and builders who
want to inspect the interaction, keyboard path, responsive behavior, and an
acquirable self-contained HTML example.

The demo has no account, remote analytics, or form-data collection. Its
deployable Cloudflare Pages artifact is the exact contents of `public/`.
Plainproof Labs publishes production updates from the `main` branch.
